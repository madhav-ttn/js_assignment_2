Q:Explain the scope chain for console.log(y) in second().

First y will be checked in local scope (where it has been called or accessed) and it's not found in function named second and then it will be checked in outer scope and now it will be checked in function named first so variable is detected with name y and value is printed; if function first does not hold the var y , then it will checked globally
